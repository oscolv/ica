> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir el Módulo ④ Ayuda: un dataset de ejemplo cargable con un clic que reproduce el WQI=88 del manual (comprobación en la propia app), la explicación del índice (qué es, tres factores, ecuaciones, categorías) y buenas prácticas + FAQ.

**Architecture:** Un ejemplo autocontenido en `src/examples/` (dos CSV parseados por el parser propio + un cargador que produce guía y datos para el store), contenido de ayuda como componentes React estáticos en `src/ui/ayuda/`, y un `AyudaModule` que ofrece el tutorial (botón "cargar ejemplo") y renderiza la documentación. Se monta en el paso `ayuda` del `AppShell`. Sin dependencias nuevas; las ecuaciones se muestran como texto legible.

**Tech Stack:** React, Vite, TypeScript, Vitest, @testing-library/react.

## Global Constraints

- Idioma del producto: español. Todo en el navegador; sin red. Diseño responsivo y compatible con tema claro/oscuro reutilizando los tokens CSS de `src/App.css`.
- Sin dependencias nuevas: la documentación es JSX; las ecuaciones se escriben como texto (no se agrega KaTeX ni un renderizador de Markdown).
- El dataset de ejemplo proviene de la Tabla 1 del manual CCME (río North Saskatchewan en Devon, 1997); al calcularse debe dar **WQI ≈ 88** (comprobación de fidelidad de la app).
- Las pruebas de componentes verifican comportamiento observable.

```ts
import guidelinesCsv from './manual-guidelines.csv?raw'
import dataCsv from './manual-data.csv?raw'
import type { GuidelineTable, DataRow } from '../engine/types'
import { parseGuidelinesCsv } from '../io/parseGuidelines'
import { parseDataCsv } from '../io/parseData'

export interface ExampleProject {
  guidelineTable: GuidelineTable
  guidelineName: string
  rows: DataRow[]
  columns: string[]
  dataName: string
}

export function loadExample(): ExampleProject {
  const { table } = parseGuidelinesCsv(guidelinesCsv)
  const { rows, columns } = parseDataCsv(dataCsv)
  return {
    guidelineTable: table,
    guidelineName: 'Ejemplo del manual (Tabla 1)',
    rows,
    columns,
    dataName: 'Río North Saskatchewan, Devon 1997',
  }
}
```

- [ ] **Step 3: Implementar `src/ui/ayuda/AyudaModule.tsx`**

```tsx
import { useState } from 'react'
import { useProject } from '../../state/ProjectContext'
import { loadExample } from '../../examples'
import { HelpContent } from './HelpContent'
import './AyudaModule.css'

export function AyudaModule() {
  const { dispatch } = useProject()
  const [loaded, setLoaded] = useState(false)

  function cargarEjemplo() {
    const ex = loadExample()
    dispatch({ type: 'loadGuideline', table: ex.guidelineTable, name: ex.guidelineName })
    dispatch({ type: 'loadData', rows: ex.rows, columns: ex.columns, name: ex.dataName })
    setLoaded(true)
  }

  return (
    <section className="ayuda">
      <div className="ayuda-tutorial">
        <h2>Tutorial rápido</h2>
        <p>
          Carga el ejemplo del manual (río North Saskatchewan, 1997) para probar ICA en un clic.
          Luego ve al paso <strong>③ Resultados</strong>: debe dar <strong>WQI = 88</strong> (categoría «Buena»).
        </p>
        <button className="ayuda-btn" onClick={cargarEjemplo}>Cargar ejemplo</button>
        {loaded && (
          <p className="ayuda-ok" role="status">
            ✅ Ejemplo cargado. Ve al paso ③ Resultados para ver el WQI = 88.
          </p>
        )}
      </div>
      <HelpContent />
    </section>
  )
}
```
